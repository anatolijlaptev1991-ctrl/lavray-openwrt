# luci/ — luci-app-lavray (заготовка)

LuCI-приложение LAVRay: минимальная интеграция в веб-интерфейс OpenWrt. Полное управление —
в веб-панели LAVRay (единый React UI из `lavray/ui/`, режим веб-панели); luci-app —
«пульт» для системных операций.

## Планируемая функциональность

- **Статус:** запущен/остановлен, активный профиль, аптайм, версия ядра, канал обновлений.
- **Управление:** старт/стоп/перезапуск службы (procd), включение автозапуска.
- **Проблемы:** индикатор ошибок из `logread`, ссылка на логи.
- **Переход:** кнопка «Открыть веб-панель LAVRay» (та же авторизация, что у демона).
- Конфигурация профилей/маршрутов — **не дублируется** в LuCI: единый источник истины —
  UCI `/etc/config/lavray` + веб-панель.

## Технические заметки

- Язык модуля: LuCI (Lua/HTM или client-side JS), зависимость `luci-compat` не планируется.
- Пакет `luci-app-lavray` — архитектурно-независимый (`all`), входит в фид (`../feed/`).
- Тексты — на 5 языках LAVRay (ru/en/de/es/zh), база — `lavray/docs/DESIGN-SYSTEM.md`.

## Статус

Заготовка Этапа 2: структура и регламент. Реализация — Этап 3, после стабилизации
`lavray-core` .ipk и веб-панели.
